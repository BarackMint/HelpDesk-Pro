# HelpDesk Pro

An internal support ticketing system built with **Laravel**, **MySQL**, and **Blade**. Designed for structured role-based ticket management across employees, support agents, and administrators.

---

## Tech Stack

| Layer      | Technology        |
|------------|-------------------|
| Backend    | Laravel (PHP)     |
| Database   | MySQL             |
| Frontend   | Blade Templates   |
| Auth       | Laravel Breeze / Sanctum |
| Version Control | Git          |

---

## Project Modules

### Module A — Ticket Management
- Create, Edit, View Tickets
- Ticket Categories & Priority
- Ticket Status & Assignment
- Ticket Filtering & Search

> Additional modules will be documented as they are built.

---

## User Roles & Permissions

### Employee / User
- Create tickets
- View own tickets
- Reply to own tickets

### Support Agent
- View assigned tickets
- Reply to tickets
- Change ticket status
- Resolve tickets

### Admin
- View all tickets
- Assign tickets to agents
- Manage users
- Manage categories
- View reports and system logs

---

## Project Setup

### Requirements
- PHP >= 8.2
- Composer
- MySQL >= 8.0
- Node.js & NPM (for frontend assets)
